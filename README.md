# Putty Chat

A simple AI chat web application built with **Next.js**, **FastAPI**, and the **OpenAI API**.  
The project demonstrates how to integrate an LLM into a real web application with streaming responses and conversation memory.

Live Demo:  
https://wanwan1026.github.io/Putty-Chat/

---

# Features

- Real-time AI chat interface
- Streaming responses from the LLM
- Conversation history (context memory)
- Simple ChatGPT-style UI
- FastAPI backend for OpenAI integration
- Deployed frontend (GitHub Pages)
- Deployed backend (Render)
